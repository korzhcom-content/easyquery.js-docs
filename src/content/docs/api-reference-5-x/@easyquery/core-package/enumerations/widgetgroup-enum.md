Represents groups of widgets. Used to identify widgets

### Enum
| Name | Value | Description | 
| --- | --- | --- | 
| All | ` Number.MAX_SAFE_INTEGER` | All. | 
| Model | ` 1 << 0` | The group of widgets responsible for Model. | 
| None | `0` | None widget group. | 
| Query | ` 1 << 1` | The group of widgets responsible for Query. | 
| Result | ` 1 << 2` | The group of widgets responsible for Result. |
