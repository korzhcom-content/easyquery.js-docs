**EasyQuery.JS lets your users build their own queries and reports inside your web app** — ad-hoc reporting, advanced search and data filtering, in a plain web page or a single-page app with Angular, React, Vue or Stencil.

Your users get the power of SQL, even if they can't pronounce it properly: all the complexity is hidden behind a query builder that is simple to use and easy to learn.

## How it fits together

EasyQuery.JS is the browser side: the query-builder widgets, the result grid and the charts. On the server, something has to turn the user's query into SQL and run it against your database. You have two options:

- **An ASP.NET Core backend:** use [EasyQuery for ASP.NET Core](https://korzh.com/easyquery/docs/introduction). It implements the [EasyQuery Web Service API](/easyquery/javascript/docs/easyquery-web-service-api) that the widgets talk to — it builds the SQL, runs it and sends the result back.
- **A backend in any other language** (Java, PHP, Node.js, Python…): use **EasyQuery Server**, a ready-made server that comes in the EasyQuery.JS package and that you install on your own infrastructure. It keeps your data models and builds the SQL from the user's query; your own backend runs that SQL and returns the result.
